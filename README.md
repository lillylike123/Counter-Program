# Counter Program

Updated version of a counter program. This version can increase, decrease, and reset a number. It has unique features such as different themes, sound effects, milestone celebrations, and combo streaks. This also allows you to have fun with numbers in a creative way. Originally, I followed a tutorial, but I added unique features to make it special! 

This was the second project I ever made with JavaScript, and I recently updated it after learning so many new skills to make it more unique to my liking. Even when I created this project, I learned so much, and I can't wait to see what I learn in the future.
